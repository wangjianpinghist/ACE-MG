# Third-party notices

The bundled evaluation and example scripts use Python's standard library. The optional audio-embedding validator uses NumPy as an installed dependency; NumPy source code is not included.

The associated research method uses the pretrained CLAP audio/text model and scientific Python libraries. This bundle contains no CLAP implementation, model weights, framework source, or third-party code tree. Users obtaining those dependencies separately should consult their respective project terms.
